## ✨ Основні можливості

- 👥 **2 Гравці на одному екрані** — класичний локальний режим.
- 🤖 **Гра проти ШІ** — вибір між легким та непереможним рівнем складності.
- 🌐 **Онлайн-мультиплеєр (P2P)** — гра з другом через інтернет за кодом кімнати або прямим лінком за допомогою **WebRTC (PeerJS)** без окремого серверного бекенду.
- 🔲 **Вибір розміру поля** — швидке перемикання між полями **3×3** та розширеним **4×4**.
- 💡 **Розумна підказка (Hint)** — динамічний розрахунок і золота неонова пульсація найкращого варіанту ходу.
- ✨ **Привид ходу (Ghost Preview)** — напівпрозорий попередній перегляд символу при наведенні мишкою.
- 🏆 **Анімація перемоги** — плавна динамічна лінія перекреслення та святкове конфеті.
- 🔊 **Звуковий супровід** — процедурні звукові ефекти, синтезовані через Web Audio API.
- 📱 **Повна адаптивність** — гра оптимізована для мобільних пристроїв, планшетів і ПК.

---

## Стек технологій

- **HTML5** — розмітка та візуальні ефекти на Canvas.
- **CSS3** — змінні, CSS Grid, Flexbox, ефект розмиття скла (Glassmorphism), неонове світіння.
- **JavaScript (ES6+)** — логіка, модулі ходів, SVG-графіка.
- **WebRTC / PeerJS** — прямий P2P-зв'язок між браузерами двох гравців.
- **Web Audio API** — процедурний синтез звукових частот.
